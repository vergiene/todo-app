# To Do List

Браузерное TODO-приложение с сохранением данных, инлайн-редактированием задач и светлой/тёмной темой — учебный проект на React.

https://todo-app-vergiene.netlify.app/

## Стек технологий

- React (функциональные компоненты, хуки)
- Vite (сборка / dev-сервер)
- Чистый CSS с кастомными свойствами (тема без фреймворков)
- SVG-иконки из [Lucide](https://lucide.dev/)
- `localStorage` браузера для хранения данных

## Архитектура

Всё состояние живёт в одном месте: `App` хранит массив `tasks` и строку `theme`, а списки активных и завершённых задач вычисляются из `tasks` при каждом рендере, а не хранятся отдельно. За сохранение отвечает `useLocalStorage` — универсальный хук, синхронизирующий любое состояние с `localStorage`; он не знает, что именно хранит — задачи или тему, — и поэтому переиспользуется для обоих случаев. Компоненты ниже `App` знают только про свою часть задачи: `ToDoForm` превращает введённый текст в объект новой задачи и передаёт его наверх через `onAddTask`; `ToDoList` — это чистый слой рендеринга, который просто раскладывает `tasks` по `ToDoItem` и сам не трогает состояние; `ToDoItem` хранит собственное локальное состояние режима редактирования (`isEdit`, `newContent`), так что редактирование одной задачи не вызывает перерендер и не затрагивает остальные, а финальный результат передаётся наверх через `handleEditTask`. `Clock` и `Theme` полностью самодостаточны — `Clock` сам управляет своим интервалом, а `Theme` просто отображает переданные ему значение темы и функцию переключения. Сама тема живёт вне React: `App` выставляет атрибут `data-theme` на `<html>`, а каждый цвет в CSS — это `var(--...)`, значение которой зависит от этого атрибута.

## Запуск локально

```bash
git clone https://github.com/vergiene/todo-app.git
cd todo-app
npm install
npm run dev
```
